AI Settings

Precedence: database setting → environment variable → application default. Leave a field blank to clear the override and fall back. These settings affect every generation, so applying them requires confirmation. Side-channel calls (memory extraction, intent discovery, memory maintenance) follow the model but keep their own measured token budgets.

Primary Generation

The model that writes every persona reply. Applies to all generation, so a change here is confirmed before it is applied.

Intent Discovery

These affect Intent Discovery only — the skill-selection classifier, never primary generation, memory extraction, continuity, or memory-engine maintenance. Blank clears the override and falls back to the code default.

Provider Routing

OpenRouter's upstream-provider routing preference for primary generation only. The only value this system currently supports is latency — no other OpenRouter routing modes have been validated against this codebase.

Security — Admin Allowlist

Admin access is the union of the ADMIN_USER_IDS environment variable (unchanged, needs a redeploy to edit) and this table (editable here). The environment ids themselves are never shown — only how many there are. The last remaining entry cannot be removed while the environment variable is empty, because that would lock everyone out.

Latency & SLA PER LLM EXCHANGE

Every figure below is measured PER LLM EXCHANGE across ALL workloads — the two user-facing on-path calls (intent discovery, primary generation) AND the async side-channels (memory extraction, continuity summarization, memory engine maintenance), which run after the reply is already delivered. It is therefore not a per-turn user-facing SLA number on its own: async outliers are included here. For the user-facing split, read the on-path rows in By Workload; for per-turn on-path latency (intent + generation only) use Slow Turns below.
