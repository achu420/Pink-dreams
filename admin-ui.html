If every call fails with a generic network/CORS error (not a JSON body from the server): this Ktor app has no CORS plugin installed, so a page opened via file:// or a different origin may be blocked by the browser. Easiest fix: ask Claude Code to install Ktor's CORS plugin (allow localhost, allow Authorization header) or to serve this file as a static route from the same app so it's same-origin.
